🎓 Sistema Escolar

    Sistema web para la organización y administración visual de información escolar.

📌 Descripción

El Sistema Escolar es un proyecto desarrollado en HTML5 que presenta una interfaz para gestionar visualmente la información de los alumnos de una institución educativa.

Incluye un formulario de registro, una tabla de alumnos y un panel de resumen.
✨ Características

    🏫 Encabezado: logotipo y nombre del sistema.
    🧭 Menú de navegación: accesos a las diferentes secciones.
    👥 Panel lateral: enlaces a alumnos, maestros y administradores.
    📝 Registro de alumnos: formulario para capturar datos personales.
    📋 Lista de alumnos: tabla con matrícula, nombre, edad, correo y acciones.
    📊 Resumen: indicadores de total de alumnos, promedio general y último alumno registrado.

🛠️ Tecnologías
Tecnología	Uso
HTML5	Estructura de la página web
Formularios HTML	Captura de información
Tablas HTML	Presentación de datos
Enlaces HTML	Navegación entre secciones

🚀 Instalación y ejecución

    Descarga el proyecto o clona el repositorio.
    Abre la carpeta Sistema-Escolar.
    Comprueba que el logotipo esté en img/logo.png.
    Abre index.html en tu navegador.

Requisitos: un navegador web moderno. No es necesario instalar dependencias para visualizar la estructura HTML.
⚙️ Estado del proyecto

Actualmente: estructura HTML de la interfaz.

Para completar la funcionalidad del sistema, se puede incorporar:

    CSS para el diseño y los estilos.
    JavaScript para registrar alumnos y actualizar las estadísticas.
    Una base de datos para guardar la información permanentemente.

    Nota: el código HTML actual define la interfaz, pero no implementa por sí solo el registro dinámico ni los cálculos del resumen.
