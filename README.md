🎓 Sistema Escolar
📌 Descripción del proyecto

El Sistema Escolar es una página web diseñada para representar la interfaz de un sistema de administración escolar. Permite visualizar un formulario para registrar alumnos, una tabla para mostrar la lista de estudiantes y un apartado de resumen con estadísticas generales.

Este proyecto forma parte de la Actividad 16 y utiliza HTML para estructurar los diferentes elementos de la página.

🎯 Objetivo

Desarrollar una interfaz web sencilla y organizada que facilite la administración visual de la información de los alumnos de una institución educativa.

🛠️ Tecnologías utilizadas
HTML5: estructura y organización del contenido.
Formularios HTML: captura de datos de los alumnos.
Tablas HTML: presentación de la lista de alumnos.
Navegación con enlaces internos: acceso a las diferentes secciones de la página.
📋 Características principales
1. Encabezado
Logotipo de la escuela.
Título principal: Sistema Escolar.
2. Menú de navegación

Incluye enlaces para acceder a las siguientes secciones:

Inicio.
Registrar alumno.
Lista de alumnos.
Resumen.
3. Panel lateral

Contiene enlaces a los apartados de:

Alumnos.
Maestros.
Administradores.
4. Registro de alumnos

Incluye un formulario con los siguientes campos:

Nombre del alumno.
Matrícula.
Edad.
Correo electrónico.
Fecha de inscripción.

También cuenta con dos botones:

Registrar: enviar el formulario.
Limpiar: restablecer los campos del formulario.

Los campos están configurados con validaciones HTML básicas, como campos obligatorios, formato de correo electrónico y límites de edad.

5. Lista de alumnos

Presenta una tabla con las siguientes columnas:

Matrícula.
Nombre.
Edad.
Correo.
Acciones.

La tabla está preparada para mostrar la información de los alumnos registrados.

6. Resumen

Incluye tres indicadores principales:

Total alumnos: muestra la cantidad de alumnos.
Promedio general: espacio destinado a mostrar el promedio.
Último registrado: espacio destinado a mostrar el último alumno registrado.
📁 Estructura del proyecto
Sistema-Escolar/
├── index.html
├── img/
│   └── logo.png
└── README.md


Nota: El archivo HTML debe guardarse como index.html y la imagen del logotipo debe colocarse en la carpeta img con el nombre logo.png.

🚀 Instalación y ejecución
Descarga o clona el repositorio.
Abre la carpeta del proyecto.
Verifica que el archivo logo.png se encuentre dentro de la carpeta img.
Abre el archivo index.html en tu navegador web.

No se requiere instalación de dependencias ni configuración de un servidor para visualizar la estructura HTML.

⚠️ Limitaciones actuales

Este código contiene la estructura HTML de la interfaz. Para que el sistema funcione de manera completa, será necesario agregar otras tecnologías según las necesidades del proyecto:

CSS: para mejorar el diseño visual y la adaptación a diferentes dispositivos.
JavaScript: para procesar el registro de alumnos, actualizar la tabla y calcular las estadísticas.
Base de datos: para almacenar permanentemente la información, si se requiere.

Los botones y los indicadores no realizan todas esas operaciones automáticamente con el HTML actual.
